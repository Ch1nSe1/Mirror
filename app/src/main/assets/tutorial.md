# Memore（Mirror）使用手册

> 纯本地记忆工具：没有账号、没有云同步，数据只在这台手机上。
> 顶部短标签是目录，点一下跳过去；每张卡片点标题可折叠。

**三件最重要的事**

1. **导出是唯一的安全网**。换机、清数据、系统出问题，都只能靠导出包拿回来。定期做一次整体备份，见《备份》。
2. **删除是软的**：删掉的记录进回收站、可以恢复；「彻底删除 / 清空回收站」不可逆。
3. **原文不可改写**：随笔 / 对话录的正文只能删、不能改；要补内容用「增修」，每条修改留最近 5 个版本。

**第一次用（六步）**

1. 时间线右下角 ➕，随便写一条，保存。
2. 认识三个 Tab：时间线（写过什么）、回顾（这周/这月怎么样）、秒针（把时间切成一段一段）。
3. 配置 AI 端点后，在记录卡上点一次 AI 分析：情绪、标签、关联都从这一步来。
4. 试一次搜索：先字面搜，再点搜索框右端的两个相交圆切到语义搜索。
5. 设置 → 导出记忆包，做一次完整导出，确认你能把东西拿回来。
6. 需要的话再开加密和应用锁；两套是独立的。

**术语表（先看这张，后面不再解释）**

| 术语 | 一句话说明 |
|---|---|
| 时间线 | 所有记录按时间倒序排列的主界面 |
| 回顾 | 本周/本月的数据、情绪主线、本月主题、近一月洞察、档案节选 |
| 秒针 | 把时间切成「刻度」，再把刻度框进「表盘」 |
| 刻度 | 一段有名字的时期，记录按创建时间归进去 |
| 表盘 | 自己圈出的一段时期，里面装若干刻度；只管框，不参与记录归属 |
| 切片 | 刻度终结时冻结的一份快照，之后不再随时间重算 |
| 锚点 | 置顶标记，用来固定重要记录 |
| 区域 | 手动型的记录集合；新建/编辑记录时可以直接选 |
| 协议 | 和标签平行的分类，导出时可以按协议挑内容 |
| 来源 | 这条记录是谁生产的；来源决定它在关联、叙事、统计里的分量 |
| 洞察 | AI 对一条、一批或近一月记录给出的判断，带原文引文，可保存成档案 |
| 关联 | AI 在分析时顺带给出的、记录之间的有向边，带一句「为什么相关」 |

## 先跑起来

### 运行环境

- Android 8.0 及以上。
- 记录、检索、附件、图文集、导出完全离线可用；AI 能力需要自己配置端点。
- 没配 AI 时一切照常，只是分析、洞察、语义扩展不可用。

### 时间线在哪儿

- 底部三个 Tab：时间线 / 回顾 / 秒针，设置在最右。
- 时间线是主界面：顶部搜索框和图标行，右下角 ➕ 是新建菜单（随笔 / 对话录 / 草稿）。
- 顶栏右侧依次是：AI 队列（有任务时）、正序 / 倒序、视图（图文集 / 区域）、更多。
- 视图按钮受「功能控制台」控制：图文集和区域只开一个时，直接显示那一个的图标；两个都关，按钮消失。
- 列表最右边有一条时隐时现的细条：按住能拖，点一下跳到那一段。

## 记录

### 三种记录类型

- **随笔**：一整段自己的话。
- **对话录**：和 AI 的往返对话，正文分「我 / AI」两段。
- **增修**：给已有记录追加内容，不改原文；会自动建立一条「补充」关系。
- **AI 札记**：只有 Agent 能写，界面没有新建入口。

### 写好之后能挂什么

- 标签 / 协议 / 来源 / 区域 / 附件 / 锚点。
- 新增时的工具行：＋附件 ｜ ＋标签 ｜ ＋协议 ｜ ＋来源 ｜ ＋区域。
- 标签 / 协议 / 区域都是**点一行就生效**的选择层（右侧一个对号），没有确认键；只有批量改标签/协议时才有固定贴底的「确认」。

### 预设

- 新建页右上角的书签图标：把类型、来源、标签、协议、区域存成预设。
- 列表按最近使用排序；套用会覆盖这五项，正文不动，可继续手改；⋮ 里可重命名 / 删除。

### 删除、回收站、批量

- 删除进回收站（时间线顶部垃圾桶图标），可以恢复。
- 批量选择：时间线右上菜单 → 批量选择；工具栏可左右滑，导出与删除在最右。
- 批量删除锁定记录时需要输入主密码。

## 草稿

- 草稿是「在这儿写东西」：起草、半成品、跑题的想法都在草稿里；出了成品就转录成记录，不删。
- 入口：时间线右下角 ➕ → 草稿；已写过的在草稿页左上角抽屉里。
- 一块一块地存：写完点保存 → 定格成一块；长按一块可复制 / 编辑 / 讨论 / 转录 / 删除。
- 转录：长按一块 → 转录 → 选随笔或对话录，内容自动填好；记录卡上的双向箭头能跳回那本草稿。
- 草稿不进时间线、不参与搜索 / 情绪 / 统计，也不带标签 / 协议 / 附件。

## 找回来

### 搜索

- 时间线顶部是搜索框，旁边漏斗是筛选。
- 支持正文 / 备注全文检索，也可以按记录 ID 检索（短 ID、完整 UUID，带 `#` 都行）。
- 搜索激活时右下角出现「×」，点它退出搜索。

### 语义搜索

- 输入内容后，搜索框右端出现两个相交的圆：淡紫 = 开，灰 = 关。
- 语义搜索比的是「意思」而不是字面；短词（≤4 字）会自动扩几个近义词一起搜。
- 结果分数太低时列表上方标「较远的联想」；空结果说明库里确实没有相近的。
- 语义搜索不会重新分析记录：向量在保存时就算好了，搜索只是一次比对。

### 筛选

- 时间线右上菜单 → 筛选。
- 可组合：标签 / 协议、时间范围（两端都含当天）、有无附件、是否锁定。
- 组与组之间是「与」，同一组多选是「或」；生效后搜索框位置换成条件 chips。

### 记录关系

- 三种：引用 / 补充 / 更正，方向是「本条 → 目标」。
- 入口：时间线卡片类型标签下方的短 ID；弹层里选类型、粘目标 ID，分「关联」与「被关联」两栏。
- 增修会自动建一条补充关系；AI 分析时也可能给出引用边。
- 全库的边在 设置 → 向量索引 → 关联。
- 关联页可按「记录 / 概念」看，右上角时钟图标按日期区间筛；两个以上概念共同连接的同一条边会归成 `A × B` 一组，底下写「共享：…」。

## 回顾

- 入口：底部 Tab 回顾。
- 一屏里从上到下：本周条数 / 字数 / 常写字的时间 / 本月条数；情绪主线；本月主题；近一月洞察；档案节选。
- 档案：从 90 天以前挑一条记录做节选，每天一条，可换一条。
- 主题：设置 → 内容 → 主题，按月列出主题簇；点某个月看当月的主题与条数（与回顾页同一份缓存）；主题命名会参考这条记录里的概念。
- 数据口径：只统计「计入统计」来源的记录，锁定记录不进回顾。

## 情绪

- 入口：设置 → 情绪分析。
- 情绪分布：按次数 / 频率 / 强度 / 时间看四种排序；频率是「该情绪出现次数 ÷ 全部情绪次数」，强度是时间衰减后的平均权重，两者不是一个东西。
- 情绪走势：一次只读一条主情绪；左上角大数字是当前时间桶的密度，点图上的桶会切到那一段，下方卡片列出该桶里每条线的密度。
- 选情绪最多 5 条；加情绪不会换掉主情绪，只有删掉主情绪才回退到最近加的那条；点卡片里的情绪行可以直接指定主情绪。
- 默认选最近 7 天真的出现过的情绪，避免一进来最新桶全是 0。

## 洞察

- 三种读法：单条记录 / 选中的一批 / 近一月。
- 四个视角：隐忧、动机、在意、反证；在弹窗里点视角名切换（字居中，箭头在右端），下次记住。
- 每条按「结论 → 原文引文 → 依据」排；引文必须能在原文里找到，找不到就丢弃（防编造）。
- 保存后进入 设置 → 洞察档案；在记录洞察页或档案页可长按删除。
- 近一月取样按月分层，尽量覆盖整段时间，而不是只取最长的那几条。

## 秒针

- 秒针把时间切成可命名的**刻度**；**表盘**是框住若干刻度的一段时期。
- 秒针 Tab 右上「咬紧秒针」新建刻度；刻度卡显示名称 / 起止 / 状态（进行中 / 已定格）。
- 刻度页分「记录 / 情绪 / 总结」三段；情绪可切频率 / 强度。
- 总结页：页签下面那条栏的右上角是「编写 / 编辑」；有总结时左上角显示字数。
- 回看：右上角眼睛图标让 AI 把这段时间讲成一段话，会带上区间外相关的旧记录；再点一次眼睛收起。回看只是读，不会自动写进总结。
- 终结刻度（设了终点）会冻结一份切片，之后不再随时间重算；进行中的刻度是实时算的。
- 删除刻度只删这一段框，不删记录；记录按创建时间归属。
- 表盘页只有抬头、段清单、后记；一个刻度可以被多个表盘框住。

## 图文集

- 入口：时间线顶部「视图」按钮（相册 / 宫格图标）→ 图文集；同一个按钮里还有「区域」。
- 图文集和区域都能在 设置 → FIX 工具 → 功能控制台 里单独开关。
- 一页一条带图片的记录，左右滑动翻页；主图可点击放大，长按出菜单；缩略图可切换主图，选择会记住。
- 注脚：正文下方「写点什么…」；每条注脚带时间小字，修改后追加「改 时间」。
- 注脚随导出/导入走（锁定记录除外）；主图选择只存在本机。

## AI

### 配置

- 入口：设置 → AI 配置；顶部在「本地 / API」之间切。
- 本地与 API 各有一套端点 / 模型；API Key 只存在本机。
- 预设：点「预设」从卡里选，选中项右侧打勾；可以新建、长按删除。
- 思考开关打开后，再选「高 / 最高」思考强度。
- 用 API 模式时，被分析的记录内容会发给你配置的服务商。
- 没配 AI 时，记录、检索、附件、图文集、导出全部可用，只有 AI 相关功能不可用。

### 生成总结与分析

- 入口：记录卡右上角「生成总结 / 重新生成总结」。
- 流程：入队 → 状态圈变化 → 成功后卡片出现总结图标；顶部队列图标可查看 / 取消任务。
- 排队中 / 等待服务 / 失败三种状态在队列里可见；失败不会自动重试。
- 默认不产出文本总结；需要那段分析性回应，去 设置 → 提示词 选「输出总结」预设。
- 没产出总结时保留原有总结，不覆盖。

### 提示词与索引

- 设置 → 提示词管理；每个功能都有默认提示词，自定义覆盖默认、保存后立即生效；修改前建议先备份。
- 设置 → 向量索引：覆盖率、已建向量、跳过（锁定 / 过短）、失败；日常增量建索引，换模型或索引坏了才需要重建。
- AI 记录：每次分析的候选、产出边数、丢弃数、耗时、失败原因。

## Agent 连接

把手机变成 agent 的记忆库：电脑上的客户端通过局域网 HTTP 读你的记录；往库里写要在 App 里点头。

### 接一次（DSH）

1. 设置 → Agent 连接，打开「服务」开关，左上角变成「运行中」。
2. 点「本机连接串」右侧 ⋯ →「复制连接串」。
3. 电脑上装 `memore-bridge` 插件（`dsh plugin --profile <profile> add <仓库路径或 tgz>`）。
4. DSH →「设置 → 插件配置 → memore-bridge」，把连接串粘进 `url`，保存。
5. 对 agent 说一句「我最近写了什么」，它会调用 `memore_recent`。

### 其它客户端

- 只认一条串的：用「复制连接串」。
- 地址、令牌分两个字段的：用「复制地址」+ 令牌行的「复制」。
- 地址形如 `http://<手机 IP>:8790`，请求头带 `X-Memore-Token`。

### 写入模式

- 只读：agent 只能看。
- 批准：写进「信」，你在那里点头才落库。
- 自动：直接写，不建议常开。

### 令牌

- 重置会让所有已配客户端立刻失效，需要重新复制连接串。

### 反向通道（电脑端点）

- 这一项是反方向：App 去连电脑上的服务，和「电脑连手机」不是一回事；没配就留空。

### 注意

- 只在家里 Wi-Fi 或自己的组网里用，别把 8790 暴露到公网。
- 令牌等于库的读写权限，别贴进截图，也别提交到仓库。

## 来源与区域

### 来源

- 时间线 →「更多」→ 来源。每个来源有四项：
  - **叙事分量**：话题、情绪、洞察取样按它加权；0 = 不算进我的叙事。
  - **结构分量**：关联候选的排序与边的权重；0 = 不参与关联。
  - **关联准入**：相似度低于它不进关联候选；1 = 永不进。
  - **计入统计**：开关；关掉后不进回顾页的条数、字数、情绪比例。
- 未标来源按 1 参与一切。

### 区域

- 入口：时间线顶部「视图」→ 区域；或卡片菜单「设置区域」。
- 只列手动型区域（自动条件型的区域不在这里出现）；可多选。
- 记录保存后才写进区域。

### 声音与外观

- 主题：设置 → 更换主题配色（六套，配色在代码里）。
- 声音总开关：设置里可以整体关掉提示音。
- **仓库不包含音频文件**（作者自用素材，不随开源分发），按仓库构建的版本没有任何提示音；想要声音需自行放入 `app/src/main/assets/sounds/`。
- 语音实验室：把文字翻成英语再交 TTS 合成（默认 `language=english`），需要自备 TTS 服务；提示音也只在这里。仓库默认不带日语翻译提示词。

## FIX 工具

- 入口：设置 → FIX 工具。
- 功能控制台：按功能显示 / 隐藏入口。图文集和区域可以分别开关（只开一个时顶栏直接显示那个图标，两个都关就消失）；还能关时间线排序、Agent 连接、洞察档案、向量索引等。
- 数据清算：清理空标签组；清空全部关联（N 条）；清空全部概念（N 个）。后两项会再确认一次，清空不可恢复。
- 脱敏导出：导出前把正文、人名等敏感内容替换掉再用。
- 系统提示：全局追加给 AI 的规则；可以整体暂停。

## 备份

- 原则：整体备份 = 换机 / 恢复；导出记忆包 = 给 AI 或挑选范围；批量导出 = 即时补信息。

### 导出

- 入口：设置 → 导出记忆包；可导出 JSON 或完整数据包（JSON + 附件 ZIP）。
- 范围：全部 / 最近 7 天 / 最近 30 天 / 自定义；可按协议、刻度、标签、区域、来源筛选（整体备份忽略筛选）。
- **锁定记录默认不导出**；勾选包含锁定 / 整体备份才带上（锁定记录的正文本来就是明文，只是界面遮蔽）。
- **API 密钥默认不导出**；整体备份可勾选包含。
- 普通导出默认不带草稿；整体备份强制带草稿、回收站、历史版本、图文集状态、设置、提示词、AI 记录与洞察档案。

### 导入

- 先预览再确认；重复记录（同 id）跳过；失败整体回滚并清理临时文件。
- 本机已有密码时，锁定记录按本机密码处理；本机没有密码时，继承包里的加密配置与密保。
- 旧包能读；新包进旧版会被忽略未知字段，升级前先备份。

## 加密

### 应用锁

- 4 位 PIN + 密保问题；启动时解锁；关闭前要验证 PIN。
- 与应用锁独立的是记录加密（主密码），可以只开一个。

### 记录加密

- 入口：设置 → 加密管理；没设过密码会先进设置页。
- 密码规则：五条（8 位以上、大写、小写、数字、符号）满足四条即可；设置时必须同时设密保问题。
- **门闩式（v5）**：内容本身是明文，密码只是一把门闩；数据库里只存校验值，没有密文、没有可被还原的主密钥。
  - 锁定记录对你来说只读、界面遮蔽；查看时才要密码。
  - 改密码可以同时改密保；密保答案用来重置密码。
  - 清除加密 = 解锁全部记录，密码与密保保留。
- 忘记密码：用密保答案重置；密保也忘了就只能放弃锁定记录——没有后门。
- 导入别的设备的包：本机已有密码时用本机密码；没有密码时继承包里的密码与密保。

## 出问题

### 忘记主密码

- 用密保答案重置。密保也忘了，锁定记录就打不开——设完密码请马上导一次整体备份。

### 换手机

1. 旧机做一次整体备份。
2. 新机装好 App，导入这个包。
3. 新机重设应用锁 PIN（不随包走）。
4. 检查 AI 端点 / Key、主题、来源权重、密保是否正常。

### AI 不动 / 状态圈变红

- 先确认 AI 服务在跑、端点可达、Key 有效；失败不会自动重试，需要手动再点。
- 记录已锁定、内容为空、模型输出格式不稳，都会失败。

### 导入不进来

- 确认是本 App 导出的包；带 `import_enabled:false` 的会被拒绝并损坏。
- 数据库版本不一致时预览会提示；重复记录跳过不算失败。

### 搜不到 / 没声音

- 中文是整词 / 前缀命中，不是任意子串；也可能在回收站里（不进搜索）。
- 没声音先看声音总开关，再确认音频文件是否真的存在（仓库不含）。

### 已知限制

- AI 依赖模型输出格式，格式不稳会解析失败；不自动重试；云端可能超时 / 截断。
- 检索中文是整词 / 前缀命中；按 ID 仅包含匹配。
- 记录关系入口只在时间线卡片上；附件不预加载，首次打开会有短暂加载。
- Compose 自绘界面上系统长截屏找不到可滚动控件，普通截图不受影响。
